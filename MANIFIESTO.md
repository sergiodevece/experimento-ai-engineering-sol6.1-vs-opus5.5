## Privacidad, derechos y trazabilidad
Las capturas completas muestran otras ventanas, interfaces y datos potencialmente personales. **No se publican sin recorte/revisión**. Los WAV contienen material de Apple Loops, por lo que no se suben a este repositorio público hasta aclarar la redistribución permitida. La existencia de archivos de pruebas en este chat no equivale a licencia de publicación pública.

Las correcciones externas de la primera versión Opus y las autorizaciones explícitas para instalar la versión Claude Code se identifican por separado. Aprobar un smoke no equivale a una certificación comercial.

**No se publican como productos comerciales los prototipos de este estudio.**
